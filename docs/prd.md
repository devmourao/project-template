# PRD — Nome do Projeto

## 1. Problema e Objetivo

- **Dor:** Qual problema real está sendo resolvido?
- **Público-alvo:** Quem vai utilizar?
- **Critério de Sucesso:** Como saberemos que o sistema funciona bem?

## 2. Escopo do MVP (O que ENTRA)

- [ ] Funcionalidade principal 1
- [ ] Funcionalidade principal 2
- [ ] Login com acesso rápido de demonstração (1 clique)

## 3. Fora de Escopo (O que NÃO entra agora)

- Funcionalidade complexa deixada para v2 (evita over-engineering)

## 4. Regras de Negócio Críticas

1. Ex: O cálculo de custo nunca pode retornar valor negativo.
2. Ex: Usuários visitantes não podem excluir registros padrão do sistema.
